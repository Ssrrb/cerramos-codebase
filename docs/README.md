# Internal Docs

`docs/` is the internal documentation app and the home for cross-project knowledge.

Put product intent, architecture, repo guidance, and package or app reference material in `docs/content/docs/`.
Prefer section landing pages and links over repeating the same prose in local folders.

Use local `README.md` files only for true ownership boundaries.
`apps/docs` is separate: it owns the public Mintlify docs surface, not internal repo guidance.
