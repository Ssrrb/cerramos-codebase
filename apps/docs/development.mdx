<Info>
  Run these commands from `apps/docs`, the Mintlify content directory. The root
  `docs/` workspace is a separate internal docs app and is not part of this
  public Mintlify surface.
</Info>

## Local preview

```bash
bun run --cwd apps/docs dev
```

The project script calls `scripts/dev-docs.sh`, which starts the Mintlify preview from the correct directory.

## Check links

```bash
bun run --cwd apps/docs lint
```

This runs Mintlify broken-link validation against the files configured in `apps/docs/mint.json`.

## Editing rules

<AccordionGroup>
  <Accordion icon="file-pen" title="Add a page">
    Create a new `.mdx` file under `apps/docs`, add frontmatter, then include the slug in `apps/docs/mint.json` and `apps/docs/docs.json` if both config formats are still kept.
  </Accordion>
  <Accordion icon="image" title="Use marketing visuals">
    Place public docs images in `apps/docs/images`. The current Cheki screenshots mirror `apps/web/public/marketing/screenshots` so the docs feel connected to the landing page.
  </Accordion>
  <Accordion icon="boxes" title="Document template behavior">
    Keep template notes in the Template section. Cheki product rules should not be mixed with generic next-forge defaults.
  </Accordion>
</AccordionGroup>

<Warning>
  Do not point this docs site at root `docs/content/docs`. That workspace is for internal Fumadocs content.
</Warning>
