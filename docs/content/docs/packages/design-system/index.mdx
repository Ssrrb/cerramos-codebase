`@repo/design-system` is the shared UI foundation for the repo.
It owns reusable primitives, composed interface building blocks, styling, and theme helpers used across apps.

It does not own app-specific page composition, product business logic, or Storybook stories.
When a component becomes shared, move it here and update consuming apps in the same PR.
