## Una sola historia

Cerramos no existe para “digitalizar comercios” en abstracto. Existe para **convertir un clic en un pedido claro**.  
Este espacio reorganiza la documentación alrededor de esa promesa y corta todo lo que la diluye.

## Decisiones canónicas

- El comprador debe iniciar sesión antes de completar la compra.
- Cada link vende un solo producto u oferta.
- Cada pedido del MVP contiene un solo item.
- El estado operativo del pedido y el estado del pago viven separados.
- El MVP emite un **resumen del pedido** o **comprobante comercial**, nunca una factura fiscal.

## Qué cambió respecto a las notas originales

- Se redujo la documentación a un sistema pequeño y escalable.
- Se separó la narrativa de producto de la especificación operativa.
- Se dejó `/docs` como archivo fuente, no como estructura final.
- Se aisló el corpus heredado de Pagopar como referencia secundaria, no como fuente canónica.
